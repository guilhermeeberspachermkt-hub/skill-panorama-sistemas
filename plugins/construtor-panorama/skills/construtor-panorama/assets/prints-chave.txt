# Formato: nome | caminho (junta com --site) ou URL | opções do shot.mjs (node scripts/shot.mjs --help)
# O número antes do primeiro "-" é o que o --so usa (--so 03,04 refaz só esses dois).
# A MESMA lista serve aos três passos:
#   1. node scripts/salvar_copia.mjs --lista prints.txt --site https://www.SUA-LOJA.com.br --saida copias
#      (uma visita por página e aparelho; aqui, 5 visitas)
#   2. node scripts/rodada.mjs --lista prints.txt --offline copias --saida r1 --css proposta.css --depois-de "seu-tema.css"
#      (sem rede, segundos por rodada: itere o CSS aqui)
#   3. node scripts/rodada.mjs --lista prints.txt --site https://www.SUA-LOJA.com.br --saida final --css ... (no ar,
#      uma vez, para confirmar; com --replace no lugar de --css, simula a gravação do arquivo inteiro)
#
# Rolagem: --scroll-y N (px) serve em qualquer tema. Com o seletor do catálogo da família, o print cai sempre no
# mesmo lugar: ex. na família /dist, --scroll-to ".product-tabs-header" --offset -10 (o meio do produto) e
# --scroll-to ".category-information" --offset -20 (o topo da lista); confira no catalogo-tema-base.md.
